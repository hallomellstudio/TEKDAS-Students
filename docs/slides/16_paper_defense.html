20  Paper & Final Defense

Minggu 16 — Evidence, contribution, reproducibility

21 Minggu 16

21.1 Final output = evidence package

Bukan hanya aplikasi.

21.2 Paper structure

Abstract
1 Introduction
2 Concepts
3 Data
4 Method
5 Experiments
6 Results
7 Discussion
8 Ethics
9 Limitations
10 Conclusion

21.3 Abstract harus punya angka

Buruk:

Model memberikan hasil yang baik.

Lebih baik:

Pada test set …, model mencapai F1 …, dibanding baseline ….

21.4 Contribution statement

Nyatakan:

REPRODUCE
ADAPT
CREATE

Lalu buktikan.

21.5 Figure minimum

Paper sebaiknya memiliki:

  1. system architecture;
  2. data/experiment flow;
  3. ML result figure/table;
  4. error/threshold analysis;
  5. UI atau LLM evidence example.

21.6 LLM evaluation wajib

Jangan hanya memberi screenshot jawaban bagus.

Laporkan test set dan failure case.

21.7 Reproducibility statement

repository
commit
dependencies
seed
commands
model name
data instructions

21.8 Oral defense

Pertanyaan utama:

“Bagian mana dari intelligence ini benar-benar berasal dari data, bagian mana dari model, bagian mana dari LLM, dan bagian mana keputusan Anda sebagai engineer?”

21.9 Grade ladder

Reproduce → C
Adapt     → B
Create    → A

Dengan syarat kualitas dan oral defense terpenuhi.

21.10 Penutup

Intelligence is not magic.

Ia adalah hasil dari:

good problem
+ trustworthy data
+ justified model
+ careful evaluation
+ grounded language
+ responsible engineering
